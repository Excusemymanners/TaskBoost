# Scurtături TaskBoost

Un singur preset, fără nimic de configurat. Scurtăturile globale merg oriunde în Windows cât timp TaskBoost rulează, inclusiv când fereastra e închisă și aplicația stă în tray (lângă ceas).

## Oriunde în Windows

| Taste | Ce se întâmplă | Când o folosești |
| --- | --- | --- |
| **Ctrl + Alt + F1** | Arată fereastra TaskBoost sau o ascunde în tray | Ca să deschizi aplicația fără să-i cauți iconița |
| **Ctrl + Alt + F2** | Gaming mode pornit / oprit | Chiar înainte să pornești un joc și din nou când termini |
| **Ctrl + Alt + F3** | Eliberează memoria | Când PC-ul merge greu, înainte să deschizi ceva mare |
| **Ctrl + Alt + F6** | Deschide Claude, care îți verifică deja PC-ul | Când vrei să-ți explice sau să-ți verifice ceva |
| **Ctrl + Alt + F7** | Trimite păianjenul de pe ecran sau îl cheamă înapoi | Când păianjenul te încurcă |
| **Ctrl + Alt + F8** | Raport rapid de sănătate, spus de păianjen | Ca să vezi dintr-o privire spațiul liber, memoria și uzura bateriei |
| **Ctrl + Alt + F9** | Modul Low power | Pe baterie, când trebuie să țină mult |
| **Ctrl + Alt + F10** | Modul Normal | Folosire de zi cu zi |
| **Ctrl + Alt + F11** | Modul Best performance | Lucru greu: randare, compilare, fișiere mari |

Gaming mode cere aprobarea de administrator, pentru că schimbă setări de sistem. Prima dată, TaskBoost se oferă să fie aprobat o singură dată pentru sesiune; după aceea nu mai întreabă până îl închizi. Pune totul înapoi când îl oprești.

F4 lipsește intenționat: e lângă Alt+F4, care închide ferestre.

## În fereastra TaskBoost

| Taste | Ce se întâmplă |
| --- | --- |
| **Ctrl + 1** | Ecranul Acasă (scor de sănătate, setări) |
| **Ctrl + 2** | Ecranul Boost |
| **Ctrl + 3** | Ecranul Gardă |
| **Ctrl + 4** | Ecranul Pornire |
| **Ctrl + 5** | Ecranul Turbo |
| **Ctrl + 6** | Ecranul Îngrijire |
| **Tab**, apoi **Space** | Te muți pe un comutator sau buton și îl apeși |
| **Stânga / Dreapta** pe bara de taburi | Tabul anterior / următor |
| **Esc** | Închide fereastra în tray (TaskBoost rămâne pornit) |
| **F1** | Arată lista de scurtături |

## Păianjenul

| Acțiune | Ce se întâmplă |
| --- | --- |
| **Click** pe păianjen, cu oricare buton | Se face roșu și își deschide mini-meniul: cele cinci moduri de laptop ca un rând de fețe, Expresii, Caută fișiere, Deschide TaskBoost, Trage un pui de somn, Pleacă. În modul Studiu / lucru, sus apare timpul rămas din Pomodoro |
| **Tragi** păianjenul cu mouse-ul | Îl iei cu tine; când îi dai drumul se așază pe cea mai apropiată margine a ecranului |
| **Îl lași** pe o fereastră | Se așază pe fereastra aceea și te întreabă dacă programul ei să primească net focus (prioritate la internet); nu schimbă nimic până nu alegi. Îl lași pe desktop ca să oprești |
| **Click din nou** pe el, click oriunde altundeva sau **Esc** | Meniul se închide. Se închide și singur dacă mouse-ul stă departe câteva secunde |
| **Click dreapta** pe iconița din tray | Meniu: Deschide TaskBoost, Scurtături de tastatură, Întreabă Claude, trimite sau cheamă păianjenul, aprobarea de administrator pentru sesiune, Ieșire |

## De știut

- Scurtăturile folosesc taste F, nu litere, pentru că pe tastatura românească Ctrl+Alt+literă scrie diacritice (ă, î, ș, ț).
- Pe laptopurile unde tastele F reglează luminozitatea și volumul, ține apăsat și **Fn**: Ctrl + Alt + Fn + F2.
- Dacă alt program folosește deja una dintre combinații, TaskBoost notează asta în jurnal, iar acea scurtătură rămâne a celuilalt program.
- TaskBoost rulează în fundal și pornește odată cu Windows, deci scurtăturile merg imediat după logare. Se opresc doar dacă îl închizi din iconița din tray (Exit).
