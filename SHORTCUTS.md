# TaskBoost shortcuts

One preset, nothing to set up. The global shortcuts work anywhere in Windows as long as TaskBoost is running, including when its window is closed and it sits in the tray.

## Anywhere in Windows

| Keys | What happens | When to use it |
| --- | --- | --- |
| **Ctrl + Alt + F1** | Shows the TaskBoost window, or hides it to the tray | To open the app without looking for its icon |
| **Ctrl + Alt + F2** | Gaming mode on / off | Right before starting a game, and again when you finish |
| **Ctrl + Alt + F3** | Frees memory | When the PC feels heavy, before opening something big |
| **Ctrl + Alt + F5** | Phone charging mode on / off | When you plug the phone in, and again when you unplug it |
| **Ctrl + Alt + F6** | Opens Claude, already asked to look over the PC | When you want something checked or explained |
| **Ctrl + Alt + F7** | Sends the buddy away, or calls it back | When the spider is in the way |
| **Ctrl + Alt + F8** | Quick health report in the buddy's speech bubble | To see free disk space, memory and battery wear at a glance |
| **Ctrl + Alt + F9** | Low power mode | On battery, when it has to last |
| **Ctrl + Alt + F10** | Normal mode | Everyday use |
| **Ctrl + Alt + F11** | Best performance mode | Heavy work: rendering, compiling, big files |

Gaming mode and phone charging ask for administrator approval, because they change system settings. The first time, TaskBoost offers to be approved once for the session; after that it does not ask again until you exit it. Both put everything back when you switch them off.

F4 is skipped on purpose: it sits next to Alt+F4, which closes windows.

## Inside the TaskBoost window

| Keys | What happens |
| --- | --- |
| **Ctrl + 1** | Home tab |
| **Ctrl + 2** | Boost tab |
| **Ctrl + 3** | Guard tab |
| **Ctrl + 4** | Startup tab |
| **Ctrl + 5** | Turbo tab |
| **Ctrl + 6** | Care tab |
| **Tab**, then **Space** | Move to a switch or button and press it |
| **Left / Right** on the tab bar | Previous / next tab |
| **Esc** | Closes the window to the tray (TaskBoost keeps running) |
| **F1** | Shows this list |

## The buddy

| Action | What happens |
| --- | --- |
| **Click** on the spider, with either button | It turns red and opens its small menu: the five laptop modes as a strip of faces, Emotes, Search for files, Open TaskBoost, Take a nap, Go away. In Study / work mode the time left in the Pomodoro is at the top |
| **Drag** the spider | Carries it; let go and it settles on the nearest edge of the screen |
| **Drop** the spider on a window | It sits on that window and asks whether that program should get net focus (go first on the internet); nothing changes unless you say so. Drop it on the desktop to end it |
| **Click it again**, click anywhere else, or press **Esc** | The menu closes. It also closes by itself when the mouse stays away for a few seconds |
| **Right-click** the tray icon | Menu: Open TaskBoost, Keyboard shortcuts, Ask Claude, send the buddy away or call it back, administrator approval for the session, Exit |

## Good to know

- The shortcuts use F-keys, not letters, because Ctrl+Alt+letter types accented characters (ă, î, ș, ț) on Romanian and many other keyboards.
- On laptops where the F-keys control brightness and volume, hold **Fn** as well: Ctrl + Alt + Fn + F2.
- If another program already uses one of these combinations, TaskBoost notes it in its log and that one shortcut stays with the other program.
- TaskBoost runs in the background and starts with Windows, so the shortcuts are there from sign-in. They stop only if you exit it from the tray icon.
